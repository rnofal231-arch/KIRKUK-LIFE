# KIRKUK LIFE — نموذج Android أولي
مشروع تجريبي باستخدام Three.js وCapacitor. يحتوي شارعاً عراقياً تجريبياً، شخصية مدنية، سيارة قابلة للقيادة، مركبات مرور ومشاة وأزرار لمس.

## بناء APK
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (لا ترفع ZIP فقط). افتح Actions ثم Build KIRKUK LIFE Android APK ثم Run workflow. بعد نجاح التشغيل نزّل Artifact باسم KIRKUK-LIFE-debug-apk، فك ضغطه وثبّت app-debug.apk.

هذه نسخة أولية بسيطة وليست بمستوى GTA VI. تحتاج اتصال إنترنت أثناء البناء.
